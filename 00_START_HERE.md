
**To Do:** Move all these files to a folder called `ab-testing-marketing-campaigns`

### Step 2: Create GitHub Repository
1. Go to https://github.com/new
2. Name: `ab-testing-marketing-campaigns`
3. Make it **Public**
4. **Don't** initialize with README (you have one already)
5. Click "Create repository"

### Step 3: Push Your Code (Terminal/Command Prompt)
```bash
cd ab-testing-marketing-campaigns

git init
git add .
git commit -m "Initial commit: AB testing marketing campaigns analysis"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/ab-testing-marketing-campaigns.git
git push -u origin main
```

### Step 4: Add Topics to Your GitHub Repo
After pushing, go to your repo's **Settings** and add these tags:
- `ab-testing`
- `data-analysis`
- `python`
- `jupyter-notebook`
- `marketing-analytics`
- `machine-learning`

1. Open LinkedIn

4. Add a screenshot from your notebook analysis
